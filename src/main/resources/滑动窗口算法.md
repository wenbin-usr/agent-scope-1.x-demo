# 滑动窗口算法详解

## 一、核心概念

滑动窗口是一种在数据流或序列上维护一个"窗口"（连续子区间），通过窗口的**滑动（移动）**来实现高效计算的算法思想。窗口可以是固定大小的，也可以是动态调整的。

```
数据流: [1, 3, 5, 7, 9, 2, 4, 6, 8, 10]

固定窗口大小 = 3:

窗口1: [1, 3, 5]   →  滑动
窗口2:   [3, 5, 7] →  滑动
窗口3:     [5, 7, 9] → 滑动
窗口4:       [7, 9, 2]
...
```

## 二、算法实现模式

### 模式1：固定大小滑动窗口

适用于：求连续子数组的最大/最小值、平均值等问题

```python
def fixed_sliding_window(arr, k):
    """
    固定大小滑动窗口模板
    求: 窗口大小为k的连续子数组的最大和
    """
    n = len(arr)
    if n < k:
        return None
    
    # 1. 初始化: 计算第一个窗口的值
    window_sum = sum(arr[:k])
    max_sum = window_sum
    
    # 2. 滑动窗口: 每次移除左边旧元素，加入右边新元素
    for i in range(k, n):
        window_sum = window_sum - arr[i - k] + arr[i]  # 核心操作: O(1)更新
        max_sum = max(max_sum, window_sum)
    
    return max_sum

# 示例
arr = [1, 3, 5, 7, 9, 2, 4, 6, 8, 10]
print(fixed_sliding_window(arr, 3))  # 输出: 24 (窗口[9, 2, 4] -> 改为[7,9,2]不对，最大是[7,9,2]=18? 让我重算)
# 实际: 窗口和为 [1+3+5=9, 3+5+7=15, 5+7+9=21, 7+9+2=18, 9+2+4=15, 2+4+6=12, 4+6+8=18, 6+8+10=24] → 最大24
```

**时间复杂度**: O(n)，避免了每个窗口重新求和 O(n*k) 的暴力做法

### 模式2：可变大小滑动窗口

适用于：求满足某条件的最长/最短子数组等问题

```python
def variable_sliding_window(arr, target):
    """
    可变大小滑动窗口模板
    求: 和 >= target 的最短连续子数组长度
    """
    n = len(arr)
    left = 0
    window_sum = 0
    min_len = float('inf')
    
    for right in range(n):      # right指针不断向右扩展窗口
        window_sum += arr[right]
        
        # 当窗口满足条件时，尝试收缩窗口（移动left）
        while window_sum >= target:
            min_len = min(min_len, right - left + 1)
            window_sum -= arr[left]  # 移除左边元素
            left += 1                # 收缩左边界
    
    return min_len if min_len != float('inf') else 0

# 示例
arr = [2, 3, 1, 2, 4, 3]
print(variable_sliding_window(arr, 7))  # 输出: 2 (子数组[4,3])
```

### 模式3：使用双端队列优化的滑动窗口（单调队列）

适用于：求滑动窗口中的**最大值/最小值**

```python
from collections import deque

def sliding_window_max(arr, k):
    """
    单调队列实现滑动窗口最大值
    核心: 维护一个单调递减队列，队首就是窗口最大值
    """
    n = len(arr)
    dq = deque()       # 存储索引，对应的值单调递减
    result = []
    
    for i in range(n):
        # 1. 移除超出窗口范围的元素（从队首）
        while dq and dq[0] <= i - k:
            dq.popleft()
        
        # 2. 移除比当前元素小的元素（从队尾），保证单调递减
        while dq and arr[dq[-1]] <= arr[i]:
            dq.pop()
        
        # 3. 当前元素入队
        dq.append(i)
        
        # 4. 当窗口形成后，队首就是最大值
        if i >= k - 1:
            result.append(arr[dq[0]])
    
    return result

# 示例
arr = [1, 3, -1, -3, 5, 3, 6, 7]
print(sliding_window_max(arr, 3))  # 输出: [3, 3, 5, 5, 6, 7]
```

| 问题 | 窗口类型 | 时间复杂度 |
|------|---------|-----------|

| 最小覆盖子串 | 可变窗口 + HashMap | O(n) |

### 经典题：最长无重复字符子串

```python
def longest_unique_substring(s):
    """
    LeetCode #3: 最长无重复字符的子串
    """
    char_set = set()
    left = 0
    max_len = 0
    
    for right in range(len(s)):
        # 发现重复字符，收缩窗口直到没有重复
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
        
        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)
    
    return max_len

print(longest_unique_substring("abcabcbb"))  # 输出: 3 ("abc")
```

### 经典题：最小覆盖子串

```python
def min_cover_substring(s, t):
    """
    LeetCode #76: 最小覆盖子串
    在 s 中找到包含 t 所有字符的最短子串
    """
    from collections import defaultdict
    
    need = defaultdict(int)
    for c in t:
        need[c] += 1
    need_count = len(need)  # 需要满足的字符种类数
    
    window = defaultdict(int)
    have_count = 0           # 已满足的字符种类数
    
    left = 0
    min_len = float('inf')
    result = ""
    
    for right in range(len(s)):
        c = s[right]
        window[c] += 1
        
        # 当前字符满足需求
        if c in need and window[c] == need[c]:
            have_count += 1
        
        # 所有字符都满足时，尝试收缩窗口
        while have_count == need_count:
            # 更新最优结果
            if right - left + 1 < min_len:
                min_len = right - left + 1
                result = s[left:right+1]
            
            # 收缩左边界
            d = s[left]
            window[d] -= 1
            if d in need and window[d] < need[d]:
                have_count -= 1
            left += 1
    
    return result

print(min_cover_substring("ADOBECODEBANC", "ABC"))  # 输出: "BANC"
```

```java
// Sentinel 滑动窗口限流核心原理
// 将1秒划分为多个小窗口（如20个50ms的窗口）
// 统计最近1秒内所有小窗口的请求总量

public class SlidingWindow {
    private int windowCount;      // 小窗口数量
    private long windowLength;    // 每个小窗口时长
    private int[] counters;       // 每个小窗口的计数
    private long startTime;       // 起始时间
    
    public boolean allow() {
        long currentTime = System.currentTimeMillis();
        int currentWindowIndex = (int)((currentTime - startTime) / windowLength);
        
        // 重置超出滑动范围的老窗口
        int oldStart = currentWindowIndex - windowCount + 1;
        for (int i = 0; i < counters.length; i++) {
            int index = (startTime / windowLength + i) % windowCount;
            if (index < oldStart) {
                counters[index] = 0;
            }
        }
        
        // 统计滑动窗口内总请求数
        int total = 0;
        for (int i = currentWindowIndex - windowCount + 1; i <= currentWindowIndex; i++) {
            total += counters[i % windowCount];
        }
        
        // 判断是否超过阈值
        if (total < threshold) {
            counters[currentWindowIndex % windowCount]++;
            return true;
        }
        return false;
    }
}
```

```
      ┌──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┬──┐

                        ↑当前窗口

```

```java
// Resilience4j CircuitBreaker 的滑动窗口实现
// 基于环形缓冲区记录最近N次调用

public class RingBitBuffer {
    private int head = 0;
    private int size = 0;
    private int capacity;       // 窗口大小 (如100次)
    private BitSet bitSet;      // 1=失败, 0=成功
    
    public void record(boolean failed) {
        bitSet.set(head, failed);
        head = (head + 1) % capacity;
        if (size < capacity) size++;
    }
    
    public float getFailureRate() {
        if (size < capacity) return -1; // 窗口未满不计算
        int failures = bitSet.cardinality();
        return (float) failures / capacity;
    }
}
```

### Redis 滑动窗口限流实现

```lua
-- Redis + Lua 实现滑动窗口限流
local key = KEYS[1]           -- 限流key
local limit = tonumber(ARGV[1]) -- 阈值
local window = tonumber(ARGV[2]) -- 窗口时长(毫秒)
local current_time = tonumber(ARGV[3]) -- 当前时间戳

-- 1. 移除窗口外的旧记录
redis.call('ZREMRANGEBYSCORE', key, 0, current_time - window)

-- 2. 统计窗口内请求数
local count = redis.call('ZCARD', key)

-- 3. 判断是否超限
if count < limit then
    redis.call('ZADD', key, current_time, current_time)
    redis.call('PEXPIRE', key, window)
    return 1  -- 允许
else
    return 0  -- 拒绝
end
```

```python
def sliding_window_template(data):
    """
    滑动窗口万能模板
    """
    # 1. 初始化窗口指针和数据结构
```

### 关键思维要点

| 要点 | 说明 |
|------|------|
| **什么时候用？** | 问题涉及**连续子区间**，且需要**优化时间复杂度** |
| **核心优势** | 避免重复计算，将 O(n²) → O(n) |
| **左指针作用** | 收缩窗口，寻找更优解 |
| **右指针作用** | 扩展窗口，探索新元素 |
| **窗口状态** | 用 sum/count/set/map 维护窗口内信息 |
| **固定vs可变** | 固定窗口只需一个指针移动；可变窗口需双指针 |

## 六、滑动窗口 vs 固定窗口限流对比

```
                固定窗口限流              滑动窗口限流
                
时间 0-1s:      ████░░░░ (4请求)        ████░░░░ (4请求)
时间 0.9-1.1s:  ██││████││              ██││░░░░││
(临界突发)      窗口1:4 + 窗口2:4       滑动窗口始终统计最近1s
                = 瞬间8请求!             = 窗口内最多5请求 ✓
                
✅ 滑动窗口解决了固定窗口的"临界突发"问题
```
